# Bank importer test pages

Small stand-ins for the five Stage 2 test products, used by `test_filo.py`.
They are NOT copies of the shops' pages: each holds only the facts Filo read on
the real page on 20 Oct 2026 (composition, origin, price, fit words), in the
same shape a real page uses (schema.org JSON-LD, Open Graph tags, Shopify product
data, plain text). The real pages are tested by importing them in Filo Studio.
